## 2. Target Audience Profiles

### Audience A: Solar Installers & EPC Companies (B2B — Primary)

| Attribute | Detail |
|-----------|--------|
| **Who** | Licensed solar installers, electricians, EPC companies |
| **Age** | 28–55 |
| **Location** | All Cyprus (Limassol, Nicosia, Paphos, Larnaca, Famagusta) |
| **Language** | Greek (primary), English (secondary) |
| **Pain Points** | High component costs, limited brand selection, slow delivery, unreliable stock |
| **Decision Factors** | Price per watt, stock availability, brand range, credit terms, delivery speed |
| **Online Behavior** | LinkedIn, Facebook groups, Google search for wholesale pricing |
| **Est. Audience Size** | 300–600 businesses / 1,500–3,000 individuals |

### Audience B: Homeowners & Property Owners (B2C — Secondary)

| Attribute | Detail |
|-----------|--------|
| **Who** | Homeowners considering solar, property developers, rural/villa owners |
| **Age** | 30–65 |
| **Location** | All Cyprus (focus: Limassol, Paphos, Nicosia suburbs) |
| **Language** | Greek (70%), English (30% — expat community) |
| **Pain Points** | High electricity bills, ROI uncertainty, installer trust, product quality |
| **Decision Factors** | Total system cost, payback period, brand reputation, warranty, local support |
| **Online Behavior** | Facebook, Instagram, Google search, YouTube |
| **Est. Audience Size** | 80,000–150,000 households |

### Audience C: Commercial & Industrial (B2B — Tertiary)

| Attribute | Detail |
|-----------|--------|
| **Who** | Hotel owners, factory managers, agricultural businesses, commercial property |
| **Age** | 35–60 |
| **Location** | All Cyprus |
| **Decision Factors** | ROI, system size capability, project support, bulk pricing |
| **Est. Audience Size** | 2,000–5,000 businesses |

### Audience D: Real Estate Developers & Building Managers (B2B — High Margin)

| Attribute | Detail |
|-----------|--------|
| **Who** | Property developers, construction companies, building management firms, housing cooperatives |
| **Age** | 35–60 |
| **Location** | Limassol, Paphos, Nicosia, Larnaca (new-build hotspots) |
| **Language** | Greek (primary), English (Russian-speaking developers) |
| **Pain Points** | Regulatory compliance, differentiating properties, shared-roof solar complexity, per-apartment metering |
| **Decision Factors** | Per-apartment cost, regulatory simplicity, warranty length, installer availability, turnkey solutions |
| **Online Behavior** | LinkedIn, Google search for regulations, property developer associations, ETEK (engineers' chamber) |
| **Why They Need Us** | Micro inverter kits solve the apartment building solar problem — each apartment independent, no Virtual Net Metering, 25-year warranty, "solar included" marketing for units. *Note: Micro inverter EAC compliance in Cyprus is unverified — this segment is provisional pending regulatory confirmation.* |
| **Est. Audience Size** | 500–1,500 companies / decision-makers |
| **Margin Opportunity** | 140–220% on apartment kits (highest margin segment) |
