  • Meta Pixel installed on all 7sun.cy pages
  • Conversions API (CAPI) via GTM Server
  • Google Ads Conversion Tracking on forms + purchases
  • Google Analytics 4 with enhanced e-commerce
  • Google Tag Manager managing all tags
