### Four-Tier Pricing Structure (All prices ex VAT)

| Tier | Description | Markup | Visibility |
|------|-------------|--------|------------|
| **1. CIF (Linyang)** | Equipment cost from Linyang | Base | Internal only |
| **2. Installed Cost** | CIF + EPC Turnkey Adders | +€100-170k | Internal only |
| **3. Client Price** | Group order price to clients | +17.4% on Installed | Group clients |
