Your Original Request: 7 MW / 22 MWh

7 / 22 cannot be built as a balanced 1:1 system. 22 MWh does not divide into 5.015 MWh containers (nearest: 20 or 25 MWh). 7 MW at 1:1 with BCS1250K requires 5.6 PCS — not a whole number. The closest achievable balanced configurations are Option A (5/20) or Option B (6.25/25). For reference, an unbalanced 7/22 system would cost approximately €2,700,000 (~€123,000/MWh), but we do not recommend this due to mixed C-rates across strings.
Alternative container — ME 4.179 MWh (4-hour variant): Linyang also manufactures a smaller container using the same 20HC shell, liquid cooling, BMS and fire suppression, but with 10 cell packs instead of 12 (EVE 306Ah vs 314Ah in the 5.015 MWh). Five of these give 20.9 MWh — closer to 22 MWh, but still not exact. At 1:1 with BCS1000K (1.0 MW) each container delivers ~4.2h duration. However, fewer cells in the same container platform means higher €/MWh CIF cost — all container infrastructure (shell, cooling, BMS, fire suppression) is identical, just spread over 17% less energy. This container is used in other portfolio parks but does not solve the 7/22 requirement as a balanced system (5 × 4.179 MWh = only 5.0 MW / 20.9 MWh at 1:1 with BCS1000K).
Recommendation: Option A (5/20) at €2,258,900 is the best starting point — confirmed pricing, longest duration (4h), lowest €/MWh. Expand to Option B (6.25/25) later by adding one identical string with zero C-rate mismatch. If timing allows, Option C (7.5/25) with the BCS1500K covers 97% of your grid connection in one phase.

Technical Notes — Container Granularity & Ratio Rules

Why Not 7 MW / 22 MWh?

Container Granularity: Each BESS container holds exactly 5.015 MWh. Energy capacity only comes in multiples of ~5 MWh. 22 MWh is not achievable with standard containers.
ContainersActual MWhNotes
420.06Options A — closest below 22 MWh

525.08Options B and C — closest above 22 MWh

Why 1:1 Ratio for All Options?

Balanced String Architecture: All options in this proposal use a strict 1:1 PCS-to-container ratio. This ensures:

Benefits of 1:1

  • Identical C-rate across every string
  • Uniform degradation — all containers age equally
  • Balanced thermal profile (no hot spots)
  • Simplest BMS coordination
  • Clean expansion — add identical strings
  • Each string independently manageable by EMS

Risks of Mixed Ratios

  • Some containers cycle harder than others
  • Uneven degradation → premature EOL on stressed strings
  • Thermal imbalance across containers
  • BMS must manage different charge/discharge profiles
  • SOH warranty verification becomes complex
  • Harder to expand cleanly later
