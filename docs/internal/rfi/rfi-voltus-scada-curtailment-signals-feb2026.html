1. Overview & Curtailment Architecture

This document consolidates all confirmed DSO (EAC/EKED) and TSO (TSOC) SCADA signals related to curtailment and power control for BESS systems connected to the Cyprus distribution network. All signals are sourced from the EAC Technical Guide for Storage – Edition 2025.1 and the TSO ANNEX-II-Appendix-2.

Key Principle: DSO curtailment commands have absolute priority over market participation dispatch schedules. When a curtailment signal is received, the EMS must immediately override any active market or optimization schedule and comply within the required response times.

Three Layers of Curtailment Control

1 Analog Setpoints (Continuous)

The DSO sends a precise active/reactive power setpoint (in kW / kVAr) via IEC 60870-5-104 addresses 30 (P) and 31 (Q). The EMS must ramp the BESS to the commanded value within 60 seconds. This is the primary curtailment mechanism and allows any power level from 0 to Pinstalled.

2 Discrete Step Commands

Pre-defined power levels (100% / 60% / 30% / 0%) sent as double commands. These are standardized curtailment steps for network congestion management. The 0% level corresponds to full curtailment / zero export.

3 Hard Disconnect (Circuit Breaker)

Emergency disconnect via IEC address 10 (C_DC_NA_1). Opens the grid circuit breaker, physically isolating the BESS from the network. Used only for emergencies or protection events. After reconnection, a 3-minute delay and 10% PAmax/min ramp are mandatory.

3. Active Power Curtailment Signals

These are the primary curtailment signals. The DSO enables remote active power control, then sends a setpoint to limit output.

IEC Addr Type ID Direction Signal Description
25 C_DC_NA_1 DSO → Site Active Power SCADA Control Enable / Disable remote P control. Must be enabled before setpoints are accepted.
125 M_DP_NA_1 Site → DSO Active Power Control Feedback Confirms control mode is active/inactive.
30 C_SE_NB_1 DSO → Site Active Power Setpoint (kW) Range: 0 – Pinstalled. This is the main curtailment command. IEEE 754 float.
503 M_ME_NC_1 Site → DSO Active Power Setpoint Feedback Reports the actual achieved active power back to DSO.
103 M_SP_NA_1 Site → DSO Setpoint Accepted / Rejected 3-second pulse confirming receipt and acceptance of command.
EMS Requirement: When Addr 30 receives a value lower than the current output, the EMS must begin ramping down immediately (acknowledge within 3 s) and reach the setpoint within 60 seconds. Minimum interval between successive DSO commands is 20 seconds.

4. Discrete Curtailment Levels

In addition to continuous setpoints, the DSO issues pre-defined step commands (double commands) for standardized curtailment:

Level Power Output Use Case EMS Action Required
Level 1 100% of Pinstalled Normal operation No curtailment. Full dispatch per market/optimization schedule.
Level 2 60% of Pinstalled Grid congestion Limit max discharge to 60%. Adjust optimization accordingly.
Level 3 30% of Pinstalled High congestion Limit max discharge to 30%. May switch to charging if beneficial.
Level 4 0% (Zero Export) Emergency curtailment Full stop of grid export. Transition to standby or self-consumption only.

5. Reactive Power Control Signals

The DSO can independently control reactive power for voltage management and power quality:

IEC Addr Type ID Direction Signal Description
26 C_DC_NA_1 DSO → Site Reactive Power SCADA Control Enable / Disable remote Q control.
126 M_DP_NA_1 Site → DSO Reactive Power Control Feedback Confirms Q control mode active/inactive.
31 C_SE_NB_1 DSO → Site Reactive Power Setpoint (kVAr) Range: −Qmax to +Qmax. IEEE 754 float. Qmax = Pinstalled × 0.6
504 M_ME_NC_1 Site → DSO Reactive Power Setpoint Feedback Reports achieved reactive power to DSO.
104 M_SP_NA_1 Site → DSO Setpoint Accepted / Rejected 3-second pulse acknowledging Q command.

6. BESS-Specific Control Signals

IEC Addr Type ID Direction Signal Description
27 C_DC_NA_1 DSO → Site BESS Active Power SCADA Control Activate / Deactivate BESS power dispatch.
127 M_DP_NA_1 Site → DSO BESS Active Power Control Feedback Confirms BESS dispatch is active/inactive.
113 M_SP_NA_1 Site → DSO BESS Availability 1 = Available, 0 = Unavailable. Must reflect actual operational status.
102 M_SP_NA_1 Site → DSO Market Participation Status 0 = Deactivated, 1 = Activated. DSO curtailment overrides this.
Priority Rule: DSO curtailment commands (Addr 25, 30) take absolute priority over Market Participation (Addr 102). When DSO issues a curtailment setpoint, the EMS must immediately suspend market dispatch and comply with the DSO command.

7. Circuit Breaker Control (Hard Disconnect)

IEC Addr Type ID Direction Signal Description
10 C_DC_NA_1 DSO → Site Circuit Breaker Control 01 = Open (disconnect), 10 = Close (reconnect)
100 M_DP_NA_1 Site → DSO CB Status Feedback Confirms actual breaker position.
101 M_SP_NA_1 Site → DSO CB SCADA Control Mode 0 = Remote (DSO has control), 1 = Local (manual control)
Reconnection Protocol: After any CB disconnect event, the EMS must enforce a 3-minute waiting period before reconnection, followed by a power ramp rate of 10% PAmax per minute (approximately 10 minutes to full power).

Summary for Voltus EMS Integration: The EMS must implement an IEC 60870-5-104 server (slave) that listens for DSO commands on port 2404 and maps them to internal PCS control via Modbus TCP. Below are the key implementation requirements.

PrioritySourceBehavior
1Protection (local firmware)Frequency/voltage trips and LFSM-O. Cannot be overridden.

3DSO CB ControlAddr 10. Hard disconnect — highest operational command.
4Market Dispatch / OptimizationOnly active when DSO is not curtailing. Addr 102 must be active.
