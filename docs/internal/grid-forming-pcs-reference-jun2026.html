Grid-forming (GFM) and grid-following (GFL) are primarily control-architecture differences, not different transformers or battery containers. On the Kehua BCS-C-HUD platform supplied by Lighthief, both capabilities exist in the same PCS firmware — the operational mode (PQ vs VSG) is selected at commissioning or via the EMS.

1. Core difference — GFL vs GFM

GFL Grid-following

  • Locks onto existing grid V/f via PLL (phase-locked loop)
  • Injects current based on P/Q setpoints
  • Needs a live, stable grid to synchronise
  • Cannot provide synthetic inertia
  • Typical mode: PQ

GFM Grid-forming

  • Creates its own voltage/frequency reference
  • Behaves like a synchronous generator
  • Can energise dead grid sections (black start)
  • Provides synthetic inertia via VSG
  • Typical modes: VSG, VF

2. MV skid / PCS — what actually differs

Same on both (typical Linyang turnkey skid)

  • Oil-immersed MV transformer (690 V → 6–33 kV, skid-integrated)
  • LV AC bus: 690 Vac 3P3W+PE
  • DC input from Linyang 5.015 MWh containers (1,060–1,500 Vdc)
  • Protection relays, metering, MV switchgear
  • Comms: RS485, CAN, Ethernet — Modbus / IEC 61850 / IEC 104
  • Skid models T1 / T2 / T4 / T8 — packaging only; GFM capability is in the C-HUD PCS units inside

6. Operating modes & commissioning sequence

The Kehua C-HUD PCS supports grid-forming and grid-following capability in the same unit. The operating mode (PQ vs VSG) is selected during commissioning and can be managed by the EMS — no hardware change is required to move between modes.

Phased commissioning — grid-following first, grid-forming when required

The plant can be energised in grid-following (PQ) mode for the initial DSO connection, and switched to grid-forming (VSG) mode when the connection terms or grid services require it.

PhaseModeAction
Initial commissioning PQ Grid-following Synchronise to grid, prove protection, export/import, pass DSO connection tests
Operational (default) PQ Standard arbitrage / curtailment recovery — typical at energisation
When required VSG Grid-forming Enabled via EMS / PCS settings — adds synthetic inertia and droop response
Future services VSG + EMS FCR / aFRR participation when TSOC ancillary markets open (~2027–2030)

Mode switch (PQ → VSG): performed via the PCS interface / Modbus / EMS — no hardware change.
Note: Where a DSO connection agreement specifies a particular operating mode, any change to grid-forming operation will be coordinated with and approved by the DSO.

7. VSG & black start

VSG — Virtual Synchronous Generator

The inverter control loop emulates a spinning generator:

  • Frequency drops → automatic power increase (P–f droop)
  • Voltage drops → reactive power adjustment (Q–V droop)
  • Provides synthetic inertia — resists rapid df/dt
  • Configurable inertia constant H (seconds)

Black start

  1. Start from fully dead grid
  2. Battery DC → PCS creates AC in VF/VSG mode
  3. Energise local MV network via transformer
  4. Bring additional units online in parallel
  5. Resynchronise to main grid when it returns

On Cyprus's isolated island grid, GFM matters as synchronous generation retires and solar penetration rises — the grid needs inertia sources, not just power injection.

10. DSO briefing — what to show & how to explain

Documents to present

  1. EN 50549-2/10 type-test report (TÜV) — Type B generating plant
  2. Kehua C-HUD datasheet — VSG, VF, Black-Start, off-grid spec
  3. SLD showing CIPS at MV point of connection
  4. FRT / LVRT / HVRT curves
  5. P–f droop test evidence (2%, 5%, 12%)
  6. EMS architecture — mode management & AGC interface
  7. Commissioning test protocol (PQ energisation; VSG/island tests when applicable)

This plant is grid-forming because it has:

  • Type B certification under EN 50549-2/10
  • VSG-capable PCS with configurable P–f and Q–V droop
  • Off-grid capability — 690 V ±1% (proves it can form a grid, not only follow one)
  • Black-start documented procedure
  • External CIPS at MV POC
  • EMS with PQ ↔ VSG mode management

This plant is grid-following only if:

  • PCS runs exclusively in PQ mode
  • Requires live grid to synchronise — cannot establish voltage alone
  • No VSG, no black-start, no off-grid specification
30-second DSO explanation:
"Most battery inverters are grid-following — they need the grid to exist and push power into it. Our PCS is grid-forming: it behaves like a conventional generator, creates voltage and frequency reference, provides synthetic inertia through VSG control, and can black-start a dead network section. Physically it is the same transformer and switchgear — the difference is inverter control software, certified under EN 50549-2 as a Type B generating plant, with central interface protection at the connection point."
Technical DSO meeting:
"At the MV skid the hardware is standard: 690 V PCS, transformer to 22/33 kV, protection and metering. Grid-forming sits in the Kehua C-series firmware — VSG mode with P–f droop (TÜV evidence at 2%, 5%, 12%), Q–V control, and black-start. In normal operation the plant runs PQ mode like any grid-following asset. When commanded, it switches to VSG and provides synthetic inertia — which a standard GFL BESS cannot do."

11. Summary

The Lighthief BESS configuration uses Kehua BCS-C-HUD grid-forming power conversion systems, type-tested to EN 50549-2/10 as Type B generating plant. The plant can be commissioned in grid-following (PQ) mode for the initial connection and operated in grid-forming (VSG) mode — providing synthetic inertia and black-start capability — when the DSO connection terms or future ancillary-service markets require it.
