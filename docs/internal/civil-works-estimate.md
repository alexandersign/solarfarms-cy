## 6. RECOMMENDED APPROACH

### For EPC Quotations

| Tier | Description | Rate | Notes |
|------|-------------|------|-------|
| **Tier 1: Basic** | Crusher run + geotextile + compaction | **€50-55/m²** | No concrete |
| **Tier 2: Standard** | + Mesh reinforcement + cable trenches | **€65-75/m²** | Recommended |
| **Tier 3: Full** | + Concrete pads under equipment | **€90-100/m²** | Heavy containers |

### Suggested EPC Pricing Formula

```
Civil Works = Site Area (m²) × Rate (€/m²)

Where:
- Tier 1 Rate = €52/m²
- Tier 2 Rate = €70/m²
- Tier 3 Rate = €95/m²

Example (20 MWh, 882 m², Tier 2):
Civil Works = 882 × €70 = €61,740
```
