1. Project Overview

Lighthief Cyprus Ltd is seeking proposals from qualified SCADA/EMS providers for the integration, programming, and ongoing support of 47 Battery Energy Storage System (BESS) installations across Cyprus. All systems must comply with Cyprus DSO (EAC) requirements and operate under IEC 60870-5-104 protocol.

4. Technical Requirements

⚠️ PCS CAPACITY REQUIREMENT (DSO)
Total PCS nameplate capacity must be ≤ RES licensed capacity per park.
Software limiting is NOT allowed - physical installed PCS rating must match or be lower than park's licensed MW.

4.1 DSO Communication Protocol (MANDATORY)

Primary Protocol IEC 60870-5-104 REQUIRED
Transport Layer TCP/IP
Communication Link M2M (4G/LTE) or Fiber Optic
Response Time ≤ 3 seconds for command acknowledgment
Setpoint Adjustment ≤ 1 minute to reach new power setpoint
Control Accuracy ±2% of setpoint

4.2 Required SCADA Points (Per DSO)

SignalAddressType

Command Level Power Output Use Case
Level 1 100% Normal operation

4.4 Required Measurements

Category Parameters Priority

BESS Status SOC, SOH, Temperature, Charge/Discharge mode REQUIRED

Environmental Ambient temperature, Container temperature PREFERRED
Energy kWh imported, kWh exported, kVArh REQUIRED

5. EMS Functional Requirements

Required EMS Capabilities

  • Peak shaving / Load shifting optimization
  • Arbitrage optimization (time-of-use pricing)
  • Grid services participation (FCR, aFRR if available)
  • Power Plant Controller (PPC) functionality
  • Multi-site fleet management dashboard
  • Automated dispatch and scheduling
  • Historical data logging (min 2 years)
  • Alarm management and escalation
  • Remote firmware update capability
  • API integration for third-party systems

5.1 Cybersecurity Requirements

Compliance NIS2 Directive / KRITIS (if applicable) REQUIRED
Data Encryption TLS 1.3 minimum, AES-256
Authentication Multi-factor authentication (MFA)
Access Control Role-based access control (RBAC)
Data Location EU-based servers preferred
Audit Logging All user actions logged, retained 12 months minimum

7. Scope of Work

Included in Proposal

  • SCADA system design per site
  • IEC 60870-5-104 gateway programming
  • Signal mapping and point list creation
  • HMI/Dashboard development
  • DSO integration and testing
  • EMS software license (if applicable)
  • Commissioning support
  • Documentation and as-built drawings
  • Operator training
  • 12-month warranty

Excluded / Client Responsibility

  • Hardware (RTU, routers, switches)
  • Communication SIM cards
  • On-site cabling and installation
  • DSO application and fees
  • Cybersecurity hardware (firewalls)

8. Proposal Requirements

Proposal Must Include:

  1. Technical Proposal - System architecture, approach, and methodology
  2. Commercial Proposal - Itemized pricing (per site and portfolio)
  3. Experience - References for similar BESS projects (>10 MWh)
  4. Team - Key personnel and qualifications
  5. Timeline - Proposed delivery schedule
  6. Support - Post-commissioning support and SLA options
  7. Compliance - Statement of NIS2/cybersecurity compliance
