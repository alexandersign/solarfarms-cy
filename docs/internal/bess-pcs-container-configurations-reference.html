The Three Valid PCS:BESS Ratios

Fundamental Rule: Within any single BESS system, ALL PCS-to-container connections must use the same ratio. Mixing ratios within one system creates unbalanced C-rates across strings, which causes uneven degradation, thermal imbalance, and BMS coordination problems. Never mix 1:1 with 2:1 or 1:2 in the same system.

PCS:BESS Ratio Diagrams

1:1 Ratio — One PCS per One Container

Most balanced configuration. Each PCS drives exactly one container. Uniform C-rate, uniform degradation, simplest BMS coordination.

2:1 Ratio — Two PCS per One Container

Power-dense. Higher C-rate means faster charge/discharge but shorter duration. Used when MW >> MWh is needed.

1:2 Ratio — One PCS per Two Containers

Energy-dense. Lower C-rate = longer duration but slower response. For long-duration or capacity firming applications.

Expansion & Mixed-PCS Considerations

C-Rate Mixing Rule: Mixing PCS sizes within a system creates non-uniform C-rates across strings. Examples at 1:1 ratio:
• BCS1000K + BCS1250K → 0.2C vs 0.25C (small mismatch — acceptable)
• BCS1250K + BCS1500K → 0.25C vs 0.3C (small mismatch — acceptable)
• BCS1000K + BCS1500K → 0.2C vs 0.3C (50% mismatch — avoid)
Each string is independently managed by the EMS, but mismatched C-rates cause uneven degradation, thermal profiles, and SOH drift over time. Acceptable for phased expansion, not recommended for new-build.
Cleanest Approach: Build the entire system with one PCS model for uniform C-rate across all strings. For phased expansion, keep the same ratio (e.g. 1:1 throughout) and accept the mild C-rate difference — the EMS dispatches each string proportionally. Avoid mixing more than 2 PCS sizes in one system.
