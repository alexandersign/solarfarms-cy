3. Scope B — CT Specification Consultation CT

3.1 Background

The Current Transformer (CT) class, ratio, and mounting location must be defined and agreed with the DSO (EAC) before we can finalise equipment production specifications. The DSO Technical Guide specifies what CTs must do but does not prescribe specific CT class, ratio, or location — these require project-specific DSO agreement.

4.2 Design Approach

Type-based design: Parks will be grouped into ~4 standard types based on container count and MV SKID configuration. Type drawings are created once and reused. Per-park DSO packages (A9) customise the type drawings with site-specific information.

Negotiation Position

  • Lead with volume: 51 sites is an extraordinary pipeline for any Cyprus civil/electrical subcontractor. Emphasise guaranteed work over 12–18 months.
  • Push for per-MWh or per-park lump sum: Avoids scope creep. Our budget is €2,000/MWh for civil — target all-in lump sums per park size category.
  • CT consultation is urgent: CT class is a prerequisite for Linyang production order finalisation. This should start immediately — even before civil works.
  • Design drawings — type-based pricing: Push for 4 type drawings at a fixed price + per-park DSO package at a lower rate (since it's mostly customisation of the type drawings).
  • Combined scope discount: If he can cover all three scopes, negotiate a combined framework with better rates than separate engagements.
  • Payment terms: We can offer 30-day payment terms. For civil works, consider milestone-based payments (design approval / pour complete / as-built submitted).
