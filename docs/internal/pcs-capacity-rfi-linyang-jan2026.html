🚫 SOFTWARE LIMITING IS NOT ALLOWED

The Cyprus DSO has confirmed that software power limiting is NOT permitted as a means to comply with capacity requirements.

  • The physical nameplate rating of all PCS units must be ≤ licensed park capacity
  • Cannot install higher capacity PCS and configure/limit output in software
  • Each park must have correctly sized MV SKID with matching PCS configuration

Implication: We must verify that every MV SKID configuration in the quotation has total PCS nameplate ≤ licensed MW.
