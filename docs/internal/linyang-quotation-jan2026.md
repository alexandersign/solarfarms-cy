### EPC Adders Formula (Per Project)

```
Import Duty (WEIGHTED) = See breakdown below
Port & Customs         = €4,000 + (containers × €1,000)
Inland Transport       = containers × €2,360
Mechanical Install     = €20,000 + (MW × €2,500)
LV Cabling             = MW × €1,400
MV Cabling             = €3,500 per MV Skid
MV Terminations        = €2,200 per MV Skid
Protection Eng         = €5,000 (€6,000 if >5MW)
Fixed Costs            = €29,800 (Remote Trip, Export, UPS, SCADA, Docs, Insurance, Fire)
CERA License           = MWh × €100
Commissioning          = €30,000 + (MWh × €500)
```

### Import Duty Calculation (Weighted Model)

**CIF Split:**
| Component | % of CIF | TARIC Code | Duty Rate | Contribution |
|-----------|----------|------------|-----------|--------------|
| Battery Containers | 65% | 8507 60 00 90 | **0%** | 0.00% |
| PCS (in MV Skid) | 10.5% | 8504.40 | **0%** | 0.00% |
| MV Transformer | 24.5% | 8504.21/23 | **3.7%** | 0.91% |
| **TOTAL** | 100% | - | - | **~0.9%** |

**Calculation:**
```
Battery Duty    = CIF × 0.65 × 0.00 = €0
PCS Duty        = CIF × 0.105 × 0.00 = €0
Transformer Duty = CIF × 0.245 × 0.037 = CIF × 0.00907

TOTAL DUTY = CIF × 0.009 (0.9% effective rate)
```

> **Note:** MV Skid internal split: Transformer ~70%, PCS+Switchgear ~30%
> Conservative 3.7% rate used (liquid dielectric). Dry-type may be lower.
