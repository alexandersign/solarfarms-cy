1. Executive summary

The bot implements a daily (1D) StochRSI mean-reversion system on Binance BTCUSDT perpetual futures: enter after overbought exhaustion, exit primarily via a 2% trailing stop at 10× isolated leverage with optional full compound reinvest.

Long + short: one position at a time (long or short, never hedged). ~2× 1y endpoint vs long-only in sim.

Backtest What sims suggest

  • Strong compound growth in favourable multi-year windows
  • ~15 long trades/year (long-only mode)
  • 2–6 trades in 3 months is normal in quiet regimes
  • Long + short can ~2× endpoint vs long-only (1y sim)

Live What to expect

  • Lower returns after funding, slippage, execution lag
  • Similar signal count; many days with no trade
  • Lumpy PnL — months with zero closed trades
  • Validate shorts on paper before mode: both

Recommended rollout: testnet paper → fixed small notional → compound only after 30+ days of fill/signal parity with backtest.

8. What is not expected

  • Daily income — trades are sparse; many days show signal: none
  • Smooth equity curve — compound returns are lumpy and path-dependent
  • Matching backtest € to the cent — funding, slippage, VIP tier change outcomes
  • Verified third-party track record — no audited public account for this exact system

Multi-window snapshot (€1k, 10×, 2% trail):

python -c "
import sys; sys.path.insert(0,'scripts')
from datetime import datetime, timezone
import pandas as pd
from stochrsi_backtest import fetch_binance_klines
from stochrsi_leveraged import run_leveraged_backtest
from stochrsi_long_short import run
for days in [90, 180, 365, 730]:
    start_ms = int((datetime.now(timezone.utc) - pd.Timedelta(days=days+60)).timestamp()*1000)
    df = fetch_binance_klines('1d', days+100, start_ms=start_ms)
    df = df[df.index >= df.index.max() - pd.Timedelta(days=days)]
    _, fl, _ = run_leveraged_backtest(df, 2.0, start_eur=1000, leverage=10)
    _, fb, _ = run(df, 'both', 2.0, 1000)
    print(days, 'd | long', round(fl), round((fl/1000-1)*100), '% | both', round(fb), round((fb/1000-1)*100), '%')
"
