# Park Studies

Park-specific studies for Solhash pre-connection mining JV.

Each subfolder contains a study for a named project with site-specific configuration (orientation, pitch, tilt, yield).

## Structure

```
studies/
├── README.md
├── alex-anarita/          # Alex Anarita — Anarita East/West (700 m², 87 kWp)
│   ├── README.md
│   ├── park-study.md
│   └── park-config.ts
└── christos-nicosia-3.3/  # Christos Nicosia — 1.7 MWp pre-connection, bifacial
    ├── README.md
    ├── park-study.md
    └── park-config.ts
```
